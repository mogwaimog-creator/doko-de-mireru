## 2026-11-03 再確認：共通作品台帳の必須項目順（2026-10-31合意を復元）
- ユーザーが10/31に確定した構造。**共通基本情報 → 内容チェック欄 → エラー欄 → 共通補足欄 → ページ専用補足欄 → 将来追加欄** の順序を保持する。
- 共通基本情報：映画/TVタイプ＋TMDB IDを一意キーとし、作品名、原題、公開年、ポスター、あらすじ、監督、主要出演者など。掲載ページの有無に関係なく全作品で記録可能。
- 内容チェック欄：確認状況、確認日、再確認要否、必要に応じて確認対象・メモ。
- エラー欄：配信取得失敗、ポスター異常、データ不一致等の種類、発生日時、解消状況。配信の実データ本体は別の配信台帳に保存する。
- 共通補足欄：作品全体に共通する注記・補足。
- ページ専用補足欄：ページ識別子を単位として掲載箇所、見る順番、独自紹介文、受賞・興行・シリーズ解説などを保存。ページ固有の文章は他ページへ上書き波及させない。
- 新しい特集・ページが増えたらページ専用の追加項目を後ろに拡張できること。既存の項目・表示・デザイン・文章を壊さない後方互換性を必須とする。
- これは実装の**要件記録**であり、実装・検証済みという意味ではない。今後の共通作品台帳設計・テストで必須の完了条件とする。
