# 4台帳の最小構成・静的監査（2026-11-07）

対象: 開発ブランチ `work/four-ledgers-20261107`。読み取りのみのコード監査。本番Redis・TMDB・Vercelへの接続なし。

## 作品台帳
- `api/_work-ledger.js` に正規キー `movie/tv + TMDB ID`、`pageExtras`、`extensions` がある。ページ別の追加項目は可能。
- `api/_detail-metadata-cache.js` は `extensions.tmdbDetail` にTMDB詳細応答の大部分を保存する。`watch/providers` は除外するが、**共通フィールドに加えて元の詳細データも保持するため、最小容量化は未完了**。
- `WORK_LEDGER_ENABLED` と `LEDGER_WRITES_RESUME` による制御あり。既存レコードに `tmdbDetail` がなければ自動上書きせず修復エラー。

## 人物台帳
- `api/_person-ledger.js` の `compactPerson` は出演カードから `overview`、`original_title`、`popularity`、`vote_average` を除外する。
- プロフィール情報は保持。追加項目を自由に保存する専用拡張欄は、このファイルでは確認できない。
- 60日更新、書き込み停止時は既存値を読み取り、新規保存しない。

## 配信台帳
- `api/_detail-providers-cache.js` は日本の `results.JP` のみ保存。詳細ページはオンデマンド、保存後24時間を目安に再確認。
- 既存の「見る順番」ページの6時/18時更新とは**別のキー・別の更新方式**。4台帳で単一の更新方式に統一済みではない。
- 書き込み停止中でも、**既存の配信レコードは更新時にSETされ得る**。新規未保存データは保存しない。現行の凍結仕様を変更する場合は要相談。

## シーズン台帳
- 新規・更新保存の双方でエピソードあらすじを削除。オフライン模擬テスト14/14 PASS。
- 本番フラグは既定OFF。実Redis、実ブラウザ、全呼び出し元の互換性は未確認。

4. 本番接続・書き込み・移行・公開は個別承認まで実施しない。
