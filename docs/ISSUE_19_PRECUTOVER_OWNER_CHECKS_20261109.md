## Upstash

1. https://console.upstash.com/redis を開き、現在サイトで使っているDBを選びます。**別のDBを作らないでください。** 対象DBが不明なら、どれかを推測して選んで操作する必要はありません。
2. 概要・使用状況の画面で、以下を確認します。
   - 現在の容量、容量上限、表示単位。以前の201/250MBから変わったか。
   - 今月の操作回数と上限、残り。1日分のグラフの場合は、その表示期間も記録。
   - 今月の送信量と上限、残り。
   - このDBを他のサイト・機能も使っていないか。
3. 契約・支払いの表示で、無料プランか、従量課金か、上限超過時に停止するか料金が増えるかを確認します。**「今月の料金が0」だけでは無料契約と判断できません。** カードの追加や設定変更はしません。超過時の扱いが分からなければ未確認のままにします。
4. 既に無料で使える試験用DBがあるかだけ確認します。新規追加が無料か不明なら作りません。試験用接続先がなければ、現在のA案を変えず、実Upstash互換性は未確認として残します。

公開料金表の数字と現在の契約が同じとは限りません。実際の画面を優先します。

## Vercel

1. https://vercel.com/dashboard で、対象のチーム/アカウントとサイトのプロジェクトを選びます。
2. Usage（使用状況）で、プラン名、今月の処理回数・処理時間・送信量、無料枠の残り、超過時の扱いを確認します。対象期間も記録してください。
3. プロジェクトのSettings内のCron Jobsで、現在の起動先と時刻を確認します。設定は変更しません。Vercel以外から夕方18時に起動している仕組みがあれば、その存在も教えてください。
4. 作品詳細ページの月間表示回数が既存の画面で分かれば確認します。**初期HTMLへのSEO反映には、これまで静的だったHTMLを返すサーバー処理が1回増えるため**、この回数が費用見積もりに必要です。分からない場合、新しい解析サービスを追加する必要はありません。
5. 既存の失敗通知・メール通知があるか、誰がどこで確認しているかを教えてください。今回、新しい有料通知サービスは作っていません。
