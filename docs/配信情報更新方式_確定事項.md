# ドコデミレル？ 配信情報更新方式【確定・変更しない】

2026-11-02 再確認。以下はユーザーが繰り返し確定した仕様。今後、別方式を提案したり、確認し直したりしない。

1. **毎日、日本時間の朝6時と夕方18時に自動更新する。** Vercelの定期実行など、訪問者に依存しない自動処理を使う。
2. **「その時間以降の最初の訪問者アクセスで更新」は採用しない。** 訪問者に更新を任せない。
3. 配信情報は共通台帳・共有キャッシュで管理し、訪問者ごとにTMDBへ問い合わせない。
4. 作品名・公開年・紹介文・TMDB ID・ポスター等の固定情報は通常の閲覧時に再検索しない。
5. 更新失敗時は以前の配信情報を保持し、古い情報であることと取得失敗を表示する。手動確認ボタンはエラー時の補助手段であり、定時自動更新の代わりではない。
6. **追加従量課金を発生させないことを最優先にする。** 本番反映や課金設定の変更はユーザーの確認なしに行わない。

この文書は仕様を固定するための記録であり、実装変更ではない。
