## 移行時に守ること

- 全ページの既存文章・タブ・表示順・デザインを維持する。
- `movie` と `tv` の種別と TMDB ID を作品の識別キーにする。
- 作品の固定情報と、朝6時／夕方18時に更新する配信情報を分離する。
- 見る順番ページは見放題のみ、作品詳細は見放題／レンタル／購入を区別する。
- TMDBへの重複問い合わせを抑え、取得失敗を「配信なし」と表示しない。
- 管理画面の本格制作は全体移行の後にする。
- **mainへの統合と本番公開は、利用者の明示的な最終承認まで行わない。**
