# 作品台帳：エラー時の表示と書き込み停止（ユーザー確定・2026-11-07）

## 決定事項
1. 作品の正規識別は `movie/tv + TMDB ID`。同じ作品IDで新たな重複レコードを作らない。
2. 初回の異常検出時のみ、その作品IDにエラーを記録して「管理者確認待ち」にする。
3. 管理者が確認するまで、その作品IDの**固定情報への自動書き込みを停止**する。更新時にエラー履歴、件数、日時を追記・再保存しない。
4. 最後の正常な作品データがある場合、サイトではそれを表示し続ける。エラーを理由に作品を非表示にしない。
5. 初回登録時など、正常な保存データがない場合は、サイトに固定の案内文を表示する。文言は次のとおり：
   - 見出し：**作品情報を確認中です**
   - 本文：**現在、この作品の情報を確認しています。確認が完了するまで、しばらくお待ちください。**
6. 案内文はHTML/プログラム内に固定し、エラー発生ごとにRedisへ保存しない。内部エラー詳細を訪問者へ表示しない。
7. 管理者が手動確認・必要な修正を行い、「確認OK」にしたら固定情報をロックする。自動でロック解除・上書きしない。
8. 作品台帳の固定情報に対する停止であり、別管理の配信台帳の6時・18時更新は停止しない。
9. しばらくは台帳を1日1回、原則読み取り専用で点検する。エラーを見つけても自動修正しない。

## 実装時の必須確認
- エラー初回の状態遷移と、以後の**書き込みゼロ**をローカル模擬Redisで検証。
- 正常な保存データを保持したまま表示できること、正常データなしでは固定文言が表示されることを検証。
- 配信台帳の更新処理が影響を受けないことを検証。
- 旧台帳の全件走査・一括書き換え・本番接続・公開は、明示承認なく実施しない。

この文書は決定事項の固定であり、実装・テスト完了を意味しない。
