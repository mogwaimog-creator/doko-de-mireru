# 共通作品台帳：異常履歴の確認（作業ブランチのみ）

異常検出は**意図的に取得済みの作品情報を比較したときだけ**行います。通常の閲覧では比較のためのTMDB再取得をしません。保存済みの固定作品情報を自動修正しません。

## 履歴の読み取り

Redisの既存の環境変数を設定した管理者のローカル環境で、次を実行します。

```bash
node scripts/inspect-work-anomalies.js movie 597
```

映画・TV区分とTMDB IDを指定します。結果には検出日時、比較元・取得元の値、項目、確認待ち状態、検出元を含みます。コマンドはRedisの読み取りのみで、TMDBアクセスも台帳更新もしません。履歴が空なら `count: 0` です。

## 注意事項

- 同一の変更内容は30日間重複記録を抑制し、作品ごとに新しい30件を保持します。履歴は無期限保存ではありません。
- 現状は異常の「確認済み」への変更や修正確定の操作は未実装です。記録内の `pending_review` は自動で解消しません。
- 比較用の `inspectExistingWork` は明示的に呼び出すための内部関数であり、通常の閲覧・Cronには未接続です。
- 作品台帳本体と異常履歴は別のRedisキーに保存します。履歴の記録が失敗しても、元の作品情報を上書きしない設計です。
- このブランチのコードはまだ実行テスト・プレビュー確認・本番公開を終えていません。
