## 再開手順

ローカルRedisを `127.0.0.1:16379` で起動し、`REDIS_TEST_CLI` をその `redis-cli` の絶対パスへ設定する。`NODE_ENV` / `VERCEL_ENV` が `production` の場合、この仮設置は拒否する。

```bash
# 計画のみ。ネットワーク・DB書込みなし
node scripts/shadow-five-ledgers.js

# キー不要の人工データ試験。出力先はGit管理外の新しいディレクトリー
node scripts/shadow-five-ledgers.js --fixtures --serve --out /PRIVATE/shadow-fixtures
node scripts/verify-shadow-five-ledgers.js http://127.0.0.1:16382 /PRIVATE/shadow-fixture-browser

# 利用者が環境Secretsへ既存TMDB_API_KEYを登録した後だけ実行
# 最大7リクエスト。新しいキーは発行しない
node scripts/shadow-five-ledgers.js --collect --out /PRIVATE/shadow-real --serve
node scripts/verify-shadow-five-ledgers.js http://127.0.0.1:16382 /PRIVATE/shadow-real-browser

# 保存済みソースを使う再検証。再収集しない
node scripts/shadow-five-ledgers.js --packets /PRIVATE/shadow-real/source-packets.json --serve --out /PRIVATE/shadow-real-replay
```

既存のパケットファイルは上書きしない。再開時は `--packets` を使う。ポートを変更する場合は `--port 16383` 等を指定できる。収集時点から配信情報が古くなった場合は、古い状態として扱い、取得済みの実データを最新と報告しない。
