# 特別確認事項・引継ぎメモ

## 運用ルール
- **今後確認が必要な例外事項だけ**を箇条書きで記録する。通常の作業や解決済み事項を増やさない。
- 各項目に「対象・未確認の内容・暫定対応・次回確認の条件」を簡潔に書く。
- **確認が必要になったら追加し、解決したら項目を削除する。** 解決済みの項目を残して一覧を肥大化させない。
- 未確認情報を推測で確定させない。利用者向けの案内は正直に記載する。
- 原則として月1回の作品台帳点検で未解決事項を見直す。緊急の誤リンク・誤IDは随時修正する。
- このファイルは引継ぎ用のチェックリストであり、公開ページのデザインや既存の決定を変更する根拠にはしない。
