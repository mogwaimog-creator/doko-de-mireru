# 作品台帳の軽量化・関連作品ID方針（2026-11-07 合意）

## 保存する
- 正規キー: movie/tv + TMDB ID
- 既存詳細画面で必要な作品名・原題・公開日・概要・ポスター・ジャンル・上映時間/話数あたりの時間・監督・出演者・評価
- 映画シリーズを識別する collectionId など、関連グループを引くための最小限のキー
- TVのシーズン表示に必要な最小情報。詳しい各シーズン情報はシーズン台帳で管理し、追加シーズンを更新可能にする
- 確認OK、手動修正、エラー時のロックに必要な管理情報
- 関連作品は movie/tv + TMDB ID の参照だけ。共通シリーズの一覧は可能な限り一か所にまとめる

## 保存・取得しない
- おすすめ作品のID・一覧・TMDB recommendations/similar
- 原語、製作国、原作者、制作者、脚本家など今回の詳細表示に不要な項目
- TMDB詳細レスポンス丸ごと（extensions.tmdbDetail など）
- 配信情報（配信台帳で別管理）
- 他作品のタイトル・ポスター・出演者などを関連元に複製しない

## 表示互換
- 既存の映画シリーズ、TVアニメの関連劇場版、TVシーズン詳細リンクを維持
- 関連IDから作品台帳を参照。未登録IDは管理側へ報告し、閲覧時の自動TMDB検索を新設しない
- TV完結確認済みなら「全Nシーズン」、放送中/不明なら「シーズンNまで」。シーズン0を除外。総話数表示は不要
- 「おすすめ作品」は復活させない

## 作業制約
- 開発ブランチだけで段階的に実装・オフライン検証する
- 既存Redis全件スキャン、コピー、削除、一括書き換えを行わない
- 確認OK済み固定情報を自動上書きしない。衝突は初回のみ記録し管理者確認待ちにする
- 本番API切替、Redis書込み、フラグ変更、デプロイ、課金を伴う変更は別途明示的な承認が必要
- 現時点の related-work / related-group resolver は試作。保存・取得の本番接続やテスト実行は未完了
