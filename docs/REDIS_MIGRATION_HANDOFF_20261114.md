## 重要：移管前と移管後は別仕様
### A. 現在、移管完了までの緊急運用
1. 作品台帳に既存レコードがあれば、その保存済みデータを表示。
2. 作品台帳に未登録なら、**TMDBから直接取得して作品詳細を正常表示**する。
3. この直接取得結果は、上限間近の**旧Upstash作品台帳には新規保存しない**。
4. 旧Upstashの余計なコマンドが増えないように実装。急激にコマンド数が増えた場合は停止する。
5. 「台帳にないから作品詳細が503エラーになる」現状を解消することが優先。
6. この動作は移管前だけの暫定対応。恒久的な台帳未保存方式にしない。

### B. 新Redisへ移管完了後の通常運行
1. 作品台帳に既存レコードがあれば、保存済みデータを表示。固定情報・ロック・手動項目を維持。
2. 未登録作品はTMDBから新規取得し、**新Redisの作品台帳に保存**。以後は保存済み情報を使う。これが本来の確定仕様。
3. 人物・シーズンなど、一時停止していた機能は移管・テスト後に再開。
4. 配信台帳は日本の見放題・レンタル・購入を保持。13シリーズの配信更新は毎朝6時JST、通常作品は最終取得24時間後の次回アクセスで更新。失敗時は前回成功情報を保持。
5. 作品台帳V2の固定項目・確認後ロック・pageExtrasの手動固定、人物台帳のコンパクト保存等、既存仕様を変えない。
